Entry for the [make.fun](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1) competition **"The One-Line Exit"**.

One line of resignation letter: the last day, the revoked printer access, and the cake in the cloud.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> I hereby resign: my last day is Friday, my printer access is already revoked, and my goodbye cake is in the cloud.

The text is 114 characters (UTF-8, within the 1–140 limit), one line, no trailing newline.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
